# Daily for iPhone — Phase i3 (Dynamic Island) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sunny lives in the iPhone 15's Dynamic Island and on the Lock Screen as one Live Activity, "Sunny today". It has four states: progress, reminder, break and report. The buttons work without opening Daily, and the app drives everything (server pushes come in i4).

**Architecture:**
- **What to show:** pure TypeScript (`src/island/`) decides the state from the existing reminders, break and report data. A driver sends it as JSON to a small Swift Expo module, `DailyIsland`, which starts, updates and restarts the ActivityKit activity.
- **Drawing:** a SwiftUI widget extension (`targets/island`, built by `@bacons/apple-targets`) draws the Island and the Lock Screen.
- **Buttons:** the buttons are `LiveActivityIntent`s. They update the activity at once, queue the action in the App Group, and JS applies it on its next sync.
- **Shared Swift:** one Swift file, the attributes plus the store plus the intent, is compiled into both targets. A test keeps the two copies identical.

**Tech Stack:** Expo SDK 57 modules (Swift), ActivityKit, WidgetKit, AppIntents (iOS 17), `@bacons/apple-targets` 5.0.0, Vitest, EAS Build.

**Spec:** `docs/superpowers/specs/2026-10-09-daily-ios-design.md` §2. This phase is i3, "Live Activity, all four states and buttons, driven from the app". i2 (Screen Time) is waiting on Apple's Family Controls approval, so there is no phone time yet. The progress state shows the next reminder instead, and i2 adds the milestone figure.

## Global Constraints

- **Identity:**
  - bundle `com.aaronalex.daily`, widget `com.aaronalex.daily.island`
  - App Group `group.com.aaronalex.daily`
  - Apple team `B6H2KH4NKJ`
- **iOS floors:**
  - Live Activity code is guarded by `#available(iOS 16.2, *)`
  - the buttons need iOS 17 (the widget target's floor is 17.0)
  - the test device is an iPhone 15 on iOS 17+
- **Fallbacks:** reminders and report-ready still arrive as normal local notifications. The Island is extra and never replaces them.
- **Android must not change:** `DailyIsland` is optional (`requireOptionalNativeModule`), Android gets the no-op, and `pnpm test` stays green.
- **No secrets** in any file, and no push setup (that's i4).
- **Settings:**
  - Every new setting key is added to `DEFAULTS` in `src/db/settings.ts`.
  - `island` defaults to `'1'`; the spec says on after onboarding, and onboarding never turns it off.
- **Repo rules:** never stage `.codex/` or `marketing/`, and never push.

## Review Focus

1. **A button pressed while Daily is closed,** then the app opened hours later. The queued action must apply exactly once, and the Island must not jump back to the reminder already handled. *Test:* Task 2, "an action applies once and the reminder stays handled".
2. **The two Swift copies drift apart** (the app and the widget decode different `ContentState`), and ActivityKit then silently shows nothing. *Test:* the Task 4 file-identity test.
3. **The 8-hour Live Activity limit:** a stale activity is never refreshed. The driver must re-show at least every 6 h even when the state is unchanged, and Swift restarts activities older than 7.5 h. *Test:* Task 2, "re-shows after 6 hours".
4. **The user turns Live Activities off** (iOS Settings or Daily's switch). The driver must end the activity once and stop calling `show`. *Test:* Task 2, "ends once when switched off".
5. **A reminder that fired while the app was closed and is already past.** It shows as "reminder" only within 30 minutes of its time, and only if not done, snoozed or skipped. *Test:* Task 1, the `pendingReminder` window tests.

- [ ] **Step 3: Implement** `state.ts`. These are the exact rules:
  - **pendingReminder:**
    - Take `planClockSlots(reminders, states, nowMs - 30*60_000, 1)`.
    - Keep only slots where `slot.atMs <= nowMs` and `localDate(slot.atMs) === localDate(nowMs)`.
    - Drop a slot if `(states.get(id)?.lastDoneAt ?? 0) >= slot.atMs` or `(handled[id] ?? 0) >= slot.atMs`.
    - Return the latest slot that is left.
  - **Icons:** map `sceneKind(r.animation)` to SF Symbols: water → `drop.fill`, meal → `fork.knife`, tea → `cup.and.saucer.fill`, dinner → `moon.fill`, stretch → `figure.walk`. The report state uses `pencil`; progress and break use `sun.max.fill`.
  - **Colours:**
    - reminders and breaks use `ANIM_LOOK[kind].color`
    - progress uses `#F6B35E` (Sunny amber, as in the notification colour)
    - report uses `#D8D2FC`
  - **Break:**
    - `title` is `ANIM_LOOK[kind].breakTitle` when the break belongs to a reminder; otherwise "Break".
    - `line` is "Back in a few minutes".
    - `timerStartMs` is `startMs` and `timerEndMs` is `startMs + totalSec*1000`.
    - `mood` is `'calm'`.
  - **Progress:**
    - Use `nextUp(reminders, states, nowMs, () => 0)`. Pass `() => 0` because there is no phone time before i2.
    - If the next reminder is a clock reminder on the same local day: `line` is `${name} at ${formatClockTime(atMs)}` and `timerEndMs` is `atMs`.
    - If it is an interval reminder: `line` is `${name} after ${leftMin}m on your phone` and `timerEndMs` is `null`.
    - If there is none: `line` is "No more reminders today".
    - `mood` is `'happy'`.
  - **Report:**
    - Shown when `report && !reportSeen`.
    - `line` is `report.headline` if it is non-empty, otherwise "Tap to write today's story".
    - `mood` is `'glowing'`.
  - **`compact`:**
    - `'now'` for a reminder and `'Ready'` for the report.
    - `''` for progress and break, which tells Swift to show the timer.

  ```swift
  import ActivityKit
  import AppIntents
  import Foundation
  import UserNotifications

  /// Shared by the app (DailyNative pod) and the Island widget. Keep both copies identical (a test checks).
  struct SunnyAttributes: ActivityAttributes {
    public struct ContentState: Codable, Hashable {
      var phase: String; var mood: String; var title: String; var line: String; var compact: String
      var timerStartMs: Double?; var timerEndMs: Double?
      var color: String; var icon: String; var reminderId: Int?; var canBreak: Bool
    }
  }

  enum IslandStore {
    static let group = UserDefaults(suiteName: "group.com.aaronalex.daily")
    static func decode(_ json: String) -> SunnyAttributes.ContentState? {
      json.data(using: .utf8).flatMap { try? JSONDecoder().decode(SunnyAttributes.ContentState.self, from: $0) }
    }
    static func fallback() -> SunnyAttributes.ContentState? { group?.string(forKey: "island_fallback").flatMap(decode) }
    static func push(action: String, reminderId: Int?) {
      var list = (group?.array(forKey: "island_actions") as? [[String: Any]]) ?? []
      list.append(["action": action, "reminderId": reminderId ?? -1, "atMs": Date().timeIntervalSince1970 * 1000])
      group?.set(list, forKey: "island_actions")
    }
    static func scheduleSnooze(title: String, body: String, reminderId: Int?) {
      let c = UNMutableNotificationContent()
      c.title = title; c.body = body; c.sound = .default
      // ponytail: expo-notifications reads custom data from userInfo["body"]; only reminderId is needed to route the tap
      if let id = reminderId { c.userInfo = ["body": ["reminderId": id]] }
      let req = UNNotificationRequest(identifier: "island-snooze-\(reminderId ?? -1)", content: c,
                                      trigger: UNTimeIntervalNotificationTrigger(timeInterval: 15 * 60, repeats: false))
      UNUserNotificationCenter.current().add(req)
    }
  }

  @available(iOS 17.0, *)
  struct IslandActionIntent: LiveActivityIntent {
    static var title: LocalizedStringResource = "Sunny reminder action"
    @Parameter(title: "Action") var action: String
    @Parameter(title: "Reminder") var reminderId: Int
    init() {}
    init(action: String, reminderId: Int) { self.action = action; self.reminderId = reminderId }
    func perform() async throws -> some IntentResult {
      IslandStore.push(action: action, reminderId: reminderId >= 0 ? reminderId : nil)
      for activity in Activity<SunnyAttributes>.activities {
        if action == "snooze" {
          let s = activity.content.state
          IslandStore.scheduleSnooze(title: s.title, body: s.line, reminderId: s.reminderId)
        }
        if let back = IslandStore.fallback() { await activity.update(ActivityContent(state: back, staleDate: nil)) }
      }
      return .result()
    }
  }
  ```
- [ ] **Step 4: `DailyIslandModule.swift`**
  ```swift
  import ActivityKit
  import ExpoModulesCore

  public class DailyIslandModule: Module {
    public func definition() -> ModuleDefinition {
      Name("DailyIsland")

      Function("isEnabled") { () -> Bool in
        if #available(iOS 16.2, *) { return ActivityAuthorizationInfo().areActivitiesEnabled }
        return false
      }

      AsyncFunction("show") { (stateJson: String, fallbackJson: String) in
        guard #available(iOS 16.2, *), let state = IslandStore.decode(stateJson) else { return }
        IslandStore.group?.set(fallbackJson, forKey: "island_fallback")
        let content = ActivityContent(state: state, staleDate: nil)
        let started = IslandStore.group?.double(forKey: "island_started_ms") ?? 0
        let now = Date().timeIntervalSince1970 * 1000
        // iOS ends a Live Activity after 8 h; restart before then so Sunny never disappears mid-day.
        if let current = Activity<SunnyAttributes>.activities.first, now - started < 7.5 * 3_600_000 {
          await current.update(content)
          return
        }
        for a in Activity<SunnyAttributes>.activities { await a.end(nil, dismissalPolicy: .immediate) }
        _ = try Activity.request(attributes: SunnyAttributes(), content: content, pushType: nil)
        IslandStore.group?.set(now, forKey: "island_started_ms")
      }

      AsyncFunction("end") {
        guard #available(iOS 16.2, *) else { return }
        for a in Activity<SunnyAttributes>.activities { await a.end(nil, dismissalPolicy: .immediate) }
      }

      Function("takeActions") { () -> [[String: Any]] in
        let list = (IslandStore.group?.array(forKey: "island_actions") as? [[String: Any]]) ?? []
        IslandStore.group?.removeObject(forKey: "island_actions")
        return list.map { a in
          var out = a
          if (a["reminderId"] as? Int) == -1 { out["reminderId"] = NSNull() }
          return out
        }
      }
    }
  }
  ```
